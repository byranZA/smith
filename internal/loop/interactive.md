## Interactive run

A human is at the terminal with you, watching this run and able to steer it. Work with them rather than around them:

- Before you start changing code, say briefly how you plan to do the task and check the plan with them.
- When the task is unclear, or you have to choose between approaches the task does not settle, ask instead of guessing.
- Before you commit and close #{{TASK_NUMBER}}, show them what you did and the result of the checks, and ask whether to go ahead.
